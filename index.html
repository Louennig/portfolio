Objectif du projet

Concevoir un site web responsive correspondant aux attentes d’un client fictif : Tony Estanguet, président du comité d’organisation des JO 2024. L’objectif : recueillir les besoins, définir les cibles, organiser le contenu, concevoir une charte graphique et des maquettes, puis développer un site respectant les contraintes du cahier des charges.

Organisation

Projet en équipe de 3 à 4 étudiants. Chacun avait un rôle précis (rédaction, design, développement...). Travail collaboratif via Teams et dépôt Git avec points réguliers.

Étapes de réalisation

  • Expression des besoins : Rédaction d’une synthèse à partir de l’interview client fictif.

  • Maquettage : Maquettes responsive sur Figma.

  • Développement : Intégration HTML/CSS/JS et mise en place de la responsivité.

  • Soutenance : Présentation du site et justification des choix.

Outils

Figma · HTML · CSS · JavaScript · Git

Objectif du projet

Créer un jeu Snake fonctionnel en terminal selon un cahier des charges client. Le joueur contrôle un serpent qui mange des pommes sans se mordre ni heurter d’obstacles.

Organisation

Projet individuel : gestion de la conception, des tests et de l'implémentation en C.

Étapes de réalisation

  • Version 1 : Déplacement du serpent, premières fonctionnalités.

  • Version 2 : Ajout croissance du serpent et accélération.

  • Version 3 : Intégration d’obstacles et détection de collision.

  • Version 4 : Conditions de victoire, peaufinage et tests.

Documentation

Documentation générée avec Doxygen.

Objectif du projet

Explorer et comparer différentes approches algorithmiques appliquées à un Snake autonome. Optimiser le nombre de déplacements et le temps CPU requis pour atteindre les pommes sans heurter d'obstacles.

Organisation

Projet mené en binôme : collaboration sur l’idéation, l’implémentation et l’analyse des performances.

Étapes de réalisation

  • Version 1 : Algorithme simple dirigeant le serpent vers les pommes.

  • Version 2 : Réduction des déplacements inutiles.

  • Version 3 : Intégration de contraintes supplémentaires.

  • Version 4 : Version finale avec optimisations de performances.

Documentation

Dépôts commentés et rapport d’analyse sur les performances.

Outils

C · Visual Studio Code

Objectif du projet

Analyser un ensemble de fichiers pour identifier des incohérences, les corriger via Docker, puis automatiser la procédure avec des scripts PHP. Mettre en place un environnement reproductible et efficace.

Organisation

Projet réalisé en groupe : contributions à l’analyse, à la mise en place Docker et au développement des scripts.

Étapes de réalisation

  • Analyse initiale : Étude d’un lot de fichiers pour identifier les problèmes.

  • Correction : Utilisation d’images Docker adaptées pour modifier les fichiers.

  • Automatisation : Développement de scripts PHP pour automatiser les traitements.

Documentation

Documentation technique expliquant l’utilisation des conteneurs et des scripts.

Outils

Objectif du projet

Concevoir une base de données relationnelle complète pour gérer championnats de football : clubs, équipes, joueurs, matches et résultats.

Organisation

Projet réalisé en binôme : modélisation conceptuelle puis écriture des scripts SQL.

  • Exploitation : Requêtes SQL (sélection, agrégation, jointures) pour besoins métiers.

Documentation

Outils
